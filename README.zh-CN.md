## 这是什么？

Artisan 机身里有两层协作的固件：一块 **触摸屏 UI**——面板上你看到的
一切；以及主控板上 **基于 Marlin 定制化的主控固件**——真正驱动机器移动、加热、执行
作业的那一层。Snapmaker 公开了这两层的源码。本项目把这对组合从底层重塑：

- **屏幕端**：清理干净的仅用于 A400 的代码逻辑、全面重设计的界面，以及一层经过系统性审计、
  由自动化测试保障的机器命令通道；
- **主控端**：上游 Marlin 修复回移、协议解析器加固，以及运动安全修复——bug 在哪
  一层，就在哪一层修掉，绝不在界面上打补丁掩盖。

最终以原厂相同规格的标准固件升级包的形式刷入，**无需任何硬件改装**。

## 项目目标

1. **轻装前行。** 砍掉遗留的多机型支持（J1 / A350）和随之而来的所有
   死代码分支，把全部工程精力投在 Artisan 上。
2. **现代、一致的触摸 UI。** 用真正的设计系统（组件库 + 多主题 + 多语言系统）取代
   一屏一凑的补丁式堆叠。
3. **修整条栈，不修表面症状。** 屏幕与主控当作一个产品对待：缺陷在它所在的层修掉，
   两端作为一个整机包同步发布。
4. **可测试的安全性。** 屏幕端每一条下发机器的命令（FDM / 激光 / CNC）都由纯函数生成
   并配字节级单元测试；主控端解析器与运动路径加固——命令出口全链路审计，而不是哪里
   出问题补哪里。
5. **无硬件开发。** 模拟器 + 物理台架的测试环境，让整个界面和绝大多数流程在没接打印机
   的情况下开发与验证。
6. **开放、可持续。** 全量开源、架构文档齐全，做一个贡献者真正可持续维护的代码库。

## 目前的主要改进

### 屏幕端 —— 控制应用（Android）

- **A400-only 核心重构** —— 在代码层面移除遗留机型分支，应用体积和复杂度大幅缩减（~52%)。
- **设计系统 v3** —— 共享 UI 组件库 + 逐组件规格文档，内置多语言系统
  （当前支持 English / 简体中文 / Deutsch）。
- **核心流程全面重设计** —— 主页、打印准备、激光与 CNC 作业流程，以及带实时
  机器/工作坐标读数的全新引导式回零页。
- **点动与坐标系统重构** —— 可靠的点动控制面板（XY / Z / 旋转轴 / 数值键入）、带动态合法性
  校验的定位移动（Go to position）、引导式 Z 对刀 / 探针校准流程。
- **蓝牙游戏手柄控制映射** —— 支持蓝牙游戏手柄接入，把按键映射为机器控制，实现类似手轮的可预测控制。
- **激光安全钥匙** —— 无需频发输入激光验证码，使用基于 U 盘钥匙的激光操作授权，同时不破坏 U 盘
  的普通文件读写功能。
- **命令层安全审计** —— 全部 FDM/激光/CNC 下发载荷纯函数化 + 字节级单元测试；异步
  管线全局错误兜底；固件安全修复（软限位处理、对焦范围上限等）。
- **文件页智能筛查** —— 按工具头（3DP / 激光 / CNC）标注文件并在作业
  开始前拦截不适用的文件。
- **多文件格式支持** —— 兼容多种切片器输出的打印文件（Luban/Orcaslicer/Lightburn)，统一识别与处理。
- **多盘 3MF 支持** —— 支持包含多个打印盘的 3MF 文件。
- **无硬件开发体系** —— 模拟器 + 物理台架支撑日常 UI 验证，装机前有布局绑定与单元
  测试双重门禁把关。
- **点动流式改造（进行中）** —— 对刀时，指令入栈 + 瞬时取消，手动控制手感大幅提升。

### 主控端 —— 运动主板（Marlin 系）

- **上游 Marlin 修复回移** —— 将上游 Marlin 已采纳的缺陷修复成批回移到 Artisan 的
  固件基线(2.0.x -> 2.1.x)。
- **协议解析器加固** —— 修复主控串口协议解析中的死循环与长度下溢问题，畸形数据不再
  可能卡死主板。
- **防御性加固批** —— 主控代码全面补空指针守卫、越界检查与异常路径修复，外加 SACP
  结果缓存、模块指针生命周期与运动路径守卫修复。
- **运动安全修复** —— 例如手动调平时，探测点之间的抬刀动作在高量具场景下会被绝对
  钳制翻转成下压、把喷头压向热床。

## 预览版能刷到我的机器上吗？

预览版将以**覆盖屏幕端与主控端的完整固件升级包**形式发布，通过 Artisan 的标准升级
流程安装。要求与注意事项：

- **仅支持 Artisan（A400）**，不支持其它 Snapmaker 机型。
- **不支持 Snapmaker 2.0 工具头**（单喷 / 1.6W 激光等）。
- **它会同时替换屏幕端与主控板的官方固件。** 这是预览版，请预期会有 Bug。
- **预览版与正式版均可随时回退到官方原版固件**，但必须使用 U 盘刷入的方式，具体将在
  安装说明里解释。
- 安装说明将随预览版下载一起发布。
